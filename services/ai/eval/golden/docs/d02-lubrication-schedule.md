# Lubrication schedule — Line 2

| Point | Interval | Lubricant |
|---|---|---|
| Filler star wheel bearings | every 250 operating hours | food-grade H1 grease, NLGI 2 |
| Capper head chain | weekly, on Mondays | food-grade chain oil |
| Conveyor chain | daily, at the start of each shift | dry lubricant spray |
| Main gearbox | oil change every 4000 operating hours | food-grade gear oil ISO VG 220 |

## Rules

Never use a lubricant that is not food grade anywhere above the product line.

Every lubrication task is recorded in the maintenance system (CMMS) on the work order, with task code LUB-02.

Wipe off excess grease after greasing the star wheel bearings; grease that drips onto the bottle path is a contamination risk.

If a bearing is noisy or hot after greasing, report it on the same work order and tell the maintenance lead.
